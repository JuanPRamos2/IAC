Ejercicio guiado 1

Clasificador de modelos de servicio Cloud — Java · GUI · CLI · Regex · NLP

Ir al simulador

Proyecto original: cloud_models_classifier

En este repositorio: la app Java vive en app/; este sitio, en web/.

Objetivo: analizar una descripción de un servicio Cloud y clasificarla como IaaS, PaaS, SaaS o FaaS, primero con reglas y expresiones regulares, y después con un pipeline básico de NLP. La GUI y la CLI reutilizan la misma lógica.

1. Modelos que identifica

IaaSInfraestructura: VM, redes, almacenamiento, SO.
PaaSPlataforma para desplegar sin administrar servidores.
SaaSSoftware listo, normalmente por suscripción.
FaaSFunciones que reaccionan a eventos (serverless).

2. Arquitectura

Usuario
  ├─ GUI  (ClassifierWindow)
  └─ CLI  (CloudClassifier)
        │
        ▼
 ClassifierService   ← validación de entradas
        │
        ├─ RegexClassifier   (palabras clave + regex)
        └─ NlpClassifier     (minúsculas, tokens, stopwords, stems, scores)

La interfaz gráfica no contiene las reglas de clasificación. Solo captura nombre, apellido y texto, llama al servicio y muestra el modelo ganador junto con las puntuaciones.

3. NLP básico (Parte 5)

  1. Conversión a minúsculas
  2. Limpieza de signos
  3. Normalización (quitar acentos)
  4. Tokenización
  5. Eliminación de stopwords
  6. Stemming sencillo en español
  7. Identificación de términos relevantes
  8. Asignación de puntuaciones por categoría

No se usa un LLM para decidir la etiqueta: el NLP solo prepara el texto para un clasificador basado en reglas y scores.

4. Casos de prueba

Entrada Esperada Obtenida ¿Correcta?
Máquinas virtuales, almacenamiento y redes para instalar mi propio SO. IaaS IaaS Sí
Desplegar una aplicación web sin administrar servidores ni sistemas operativos. PaaS PaaS Sí
Correo electrónico en el navegador con suscripción mensual. SaaS SaaS Sí
Ejecutar una función cada vez que un usuario suba una imagen. FaaS FaaS Sí
Instancias EC2, discos persistentes y red privada para instalar Linux. IaaS IaaS Sí

7. Decisiones de diseño

  • Si el texto dice sin administrar servidores, no se cuenta como IaaS: es evidencia de PaaS.
  • Almacenamiento en un flujo de “función al subir un archivo” no gana a FaaS.
  • Si no hay evidencia o hay empate, el resultado es Indeterminado.
