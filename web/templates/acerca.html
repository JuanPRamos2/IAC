Cómo está organizado el proyecto

La carpeta del clasificador se convirtió en web/: el sitio completo. El clasificador quedó como un servicio interno, no como el nombre del producto.

Monolito

Una sola aplicación Flask sirve HTML, estáticos y API JSON. Para agregar un módulo nuevo: ruta en web/blueprints, lógica en web/services y, si hace falta persistencia, modelo en web/models.

Clasificador

Sigue clasificando texto en IaaS, PaaS, SaaS y FaaS. Se usa desde la página /clasificador o por consola con python -m web.cli --cli.

Secretos

Las claves van en .env (no se versiona). El archivo .env.example documenta las variables sin valores reales.
